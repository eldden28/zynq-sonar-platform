What this sends

A standards-compatible JANUS baseline packet generated and decoded by the CMRE reference implementation. The class, application type, capability flags, and 34-bit application-data field are exposed directly. Class 16 types 0 and 1 use registered codecs, so this raw-field UI accepts only zero data for those types.

What this does not claim

JANUS is intended for discovery and initial contact. Arbitrary text cargo requires a registered application definition and its codec plug-in; high-throughput data should switch to another negotiated waveform.

48 ksample/s audio · four reference parameter sets below Nyquist · Doppler correction enabled in the receiver · JANUS reference implementation remains a separate GPLv3 component.
