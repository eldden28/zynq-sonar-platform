# UltraZed 3EG PCIe carrier hardware build — 2026-08-15

## Scope and assumption

This is a completed Vivado implementation for carrier `AES-ZU-PCIECC-G` and
the assumed industrial SOM `AES-ZU3EG-1-SOM-I-G`. The SOM label and carrier
PCB revision have not yet been physically inspected, so the platform remains
`development`, not `validated`.

- device: `xczu3eg-sfva625-1-i`

## Implemented data path

```text
2 GB DDR4
   ^
   | ZynqMP S_AXI_HPC0_FPD
   v
40-bit AXI DMA MM2S -> 512-point FFT -> spectral filter -> 512-point IFFT -> AXI DMA S2MM
```

The data path runs from the Avnet preset's approximately 100 MHz PL clock.
Control addresses are platform-specific:

- AXI DMA: `0xA0000000`;
- spectral filter: `0xA0010000`.

Linux discovers these through the generated device tree; userspace and the
driver retain the common `cora-dsp` ABI rather than using physical addresses.
